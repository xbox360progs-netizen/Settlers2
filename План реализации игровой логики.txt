Этап 1. Базовая игровая модель

Сначала нужно отказаться от идеи "строим здания и сразу работают".

В Settlers 2 всё построено вокруг экономики.

Основные сущности:

Player
World
Map
Road
Flag
Building
Worker
Soldier
Resource
TransportJob
Этап 2. Карта

Каждая клетка должна хранить:

struct MapNode
{
    uint16_t terrain;
    uint16_t height;

    uint8_t owner;
    uint8_t object;

    uint8_t resourceType;
    uint8_t resourceAmount;

    bool road;
    bool occupied;
};
Этап 3. Система флагов

Это сердце Settlers 2.

Любой транспорт идет:

Building
   ↓
 Flag
   ↓
 Road
   ↓
 Flag
   ↓
 Building

Не напрямую.

Нужны:

class Flag
{
    Vector2i pos;

    ResourceSlot slots[8];

    std::vector<Road*> roads;
};
Этап 4. Система дорог

Игрок строит дорогу.

Дорога:

class Road
{
    Flag* start;
    Flag* end;

    std::vector<MapNode*> path;
};

После завершения:

CreateCarrier();

появляется носильщик.

Этап 5. Транспортная система

Самая важная часть игры.

Нужно реализовать:

TransportJob

например:

1 доска
из лесопилки
в склад

Структура:

struct TransportJob
{
    ResourceType resource;

    Flag* source;
    Flag* destination;

    uint32_t priority;
};
